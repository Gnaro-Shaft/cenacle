# Security policy

Cénacle handles private email, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Use GitHub's private reporting instead: *Security* tab → *Report a vulnerability*.

The project is in its design phase; there is no released version yet. Design-level concerns about the threat model (see `docs/adr/0005-injection-par-les-mails.md`) are welcome too.
