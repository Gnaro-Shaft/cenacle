# Les écarts de conformité acceptés

Les contrôles de `npm run check` (ADR-0022) comparent les registres, le cadre, le code et la documentation. Un écart connu et accepté se déclare ici, avec sa raison et sa date ; sans quoi il fait échouer la vérification. Une exception qui n'excuse plus rien est elle-même signalée : elle est à retirer.
